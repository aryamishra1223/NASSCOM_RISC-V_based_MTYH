## Introduction

This lfocuses onto the NASSCOM RISC-V based MYTH (Microprocessor for You in Thirty Hours) program conducted by VSD (VLSI System Design).
It includes the following :
- course structure
- RISC-V fundamentals
- hardware-software relationship
- learning roadmap for the workshop

---

## Topics Covered

### 1. Introduction to RISC-V
- Open-source Instruction Set Architecture (ISA)
- Modular and extensible architecture
- Widely used in academia and industry

### 2. From Software to Hardware
Understanding how:
- C programs are compiled
- assembly instructions are generated
- instructions execute on hardware

### 3. Course Structure

- Day 1 → RISC-V ISA and toolchain
- Day 2 → ABI and verification flow
- Day 3 → Digital logic and TL-Verilog
- Day 4 → Basic CPU microarchitecture
- Day 5 → Pipelined RISC-V CPU
