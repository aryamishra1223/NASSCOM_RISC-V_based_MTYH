# 45-2

## Overview

We next connect register file outputs to ALU input operands. The lecture focuses on:

- operand forwarding from the register file
- datapath signal hookup
- semantic signal naming
- ALU source operand preparation

The values read from source registers are now connected to ALU operand signals, which will later be used to:

- execute arithmetic
- logical
- comparison
- branch operations.

This lecture completes operand fetch connectivity
between the register file and the arithmetic logic unit.
